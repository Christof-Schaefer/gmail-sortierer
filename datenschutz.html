Datenschutzerklärung

Zweck: Der Gmail-Sortierer ist eine private Anwendung. Er greift ausschließlich auf das Gmail-Konto seines Betreibers zu, um eingehende E-Mails zu sortieren, zu kennzeichnen, zu archivieren, Spam auszusortieren und Benachrichtigungen per Telegram zu senden.

Verarbeitete Daten: Absender, Betreff, Datum und ein gekürzter Textauszug eingehender E-Mails.

Weitergabe: Zur automatischen Einordnung wird der gekürzte Inhalt an OpenRouter bzw. TypeSafe übermittelt, für Zusammenfassungen dringender E-Mails an Anthropic. Benachrichtigungen werden über Telegram an den Betreiber gesendet. Die Anwendung läuft auf Trigger.dev. Darüber hinaus werden keine Daten an Dritte weitergegeben, verkauft oder für Werbung genutzt.

Speicherung: Die Anwendung speichert keine E-Mail-Inhalte dauerhaft. Der Zustand wird über Gmail-Labels im eigenen Postfach gehalten; Ausführungsprotokolle bei Trigger.dev werden nach deren Aufbewahrungsfristen gelöscht.

Google-API-Daten: Die Nutzung von Daten, die über Google-APIs empfangen werden, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Widerruf: Der Zugriff kann jederzeit unter myaccount.google.com/permissions entzogen werden.
